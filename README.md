# -Detection-of-automated-traffic-Anti-bot-
Существуют внешние сервисы, которые автоматически собирают данные из объявлений: отслеживают цены, составляют сводки по категориям и выгружают контакты продавцов.
Команда Антибота подготовила выборку с разметкой на основе известных источников трафика. Положительный класс представлен трафиком нескольких сервисов автоматизированного сбора данных, отрицательный — трафиком, отнесённым к человеческому. 

Задача — по событиям внутри суточного окна построить модель, которая присваивает каждой cookie_id оценку от 0 до 1: чем выше значение, тем вероятнее принадлежность к положительному классу.

Target: 1 — трафик известных сервисов сбора данных; 0 — трафик, отнесённый к человеческому
